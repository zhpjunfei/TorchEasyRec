## 二、按预注册判据的判决（诚实版）

1. **正式判决 = 未决**【事实读数】：单 seed 过不了符号闸（3/3 同号），规则表其余行一律"未决"，禁止硬解释。
1. **点估计层面，强版假说未获支持**【事实读数】：预注册功效声明是判决"合成吸收是否 ≥0.2pp"的大效应——坐实版预测"拆掉合成后 Δ 应跳 ≥+0.15pp"未出现，两干预 |Δ|≤0.070pp ≪ 0.2pp，方向甚至轻微反向。
1. **限制如实报**【推断】：σ_Δ≈0.25pp、单 seed，Δ_C=−0.070pp 的 95% 区间仍覆盖 +0.2pp 量级（P(Δ≤−0.07 | 真效应+0.2)≈14%）——统计上不能排除大效应，只能说"两个独立干预都没看到预测方向的影子"。

## 三、绝对 AUC 诊断（非判决对象，按 P3 纪律先过容量检查）

| run    | ctr vs base  | cvr vs base | train@5500 ctr |
| ------ | ------------ | ----------- | -------------- |

| C1×F1b | **−0.421pp** | −0.384pp    | 0.71360        |
| K1×T0  | −0.034pp     | −0.008pp    | 0.71736        |

**① DCN 是通用放大器，不偏袒 T0 形态【事实读数】**：删 dcnv2 后两臂近似均摊掉 0.42~0.48pp（降幅差仅 −0.059pp）——DCN 本身值 0.4pp+ 绝对 AUC，但 P2"放大器版"强形态（Δ≤−0.15pp，DCN 特别放大 T0 信号）**也未出现**。

**② K1 容量混杂检查（P3）通过【事实读数】**：摘 kv 的绝对代价 ≈0.01~0.03pp（两臂降幅差 −0.026pp），train AUC 同向微降——不是"容量差异性打击"，Δ_K 解读有效。

**③ 新事实：kv 的模型边际贡献 ≈ 0.03pp【事实读数】**：203 条 target-keyed kv 摘掉后 AUC 几乎不动。与 SQL-6 **不矛盾**（F-B 驳的是"kv 已供给 match 信息"；这里是"kv 自身的偏好信号可被其余特征——活动度标量、序列、其他统计——替代"）。SQL 面 lift 真实 ≠ 模型边际贡献大。

**④ 非判决项备忘**：nodcn 两臂 `ema_grad_norm_ctr`（0.31~0.32）明显高于 K1 对（0.17~0.20）——DCN 移除后梯度更多落在共享主干，属预期现象。

## 四、主结论改判（回写 SQL 链 §5.7）

**强版"下游合成"（DCN 交叉吸收 ≥0.2pp）未获支持**【事实读数，单 seed】。弱合成逃逸阀仍开（PLE 深路未拆、C1K1 组合臂未跑）——按 P1 纪律：两臂 Δ≈0 **只证伪强版**，弱合成存活。

主推断修正【推断】：**T0−F1b≈0 是骨架性质，不是下游合成的 artifact**——target-aware 点积读出（单双线性）相对 self-attn 池化本身无增益，三种骨干下一致（base −0.011 / C1 −0.070 / K1 −0.037pp）。结合 T2−T0=+0.074pp（4 路读出唯一正向）：**值钱的是 4 路打分形态，target-awareness 只有配上表达性读出才兑现**——与 READOUT_20261030 的"4 路打分形态才值钱"完全同构，不再需要下游合成补丁。

"T2 的 +0.074pp 是下游难合成的残差视图"降级为与数据一致的候选解释（未经 P2 臂 T2×C1 检验）。
