### 2.3 Home场景校准分析

**修复前**：

```
home_pred_mean = 0.3656
home_actual = is_click / is_home_scene = 0.2371 / 0.6660 = 0.3560
calibration_error = 0.3656 - 0.3560 = +0.0096 ✅
```

**修复后**：

```
home_pred_mean = 0.3618
home_actual = is_click / is_home_scene = 0.2537 / 0.6821 = 0.3720
calibration_error = 0.3618 - 0.3720 = -0.0102 ✅
```

**结论**：

- 校准误差从+0.96%变为-1.02%，均在±2%健康范围内
- 修复前后校准状态良好，无明显偏移
