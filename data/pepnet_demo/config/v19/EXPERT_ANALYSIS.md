# 多场景数据专家分析与建模建议

## 一、核心数据洞察

### 正负样本分布

| 场景   | 总PV   | 正样本 | 负样本 | 正样本率 | 正负比     | 风险等级  |
| ------ | ------ | ------ | ------ | -------- | ---------- | --------- |
| home   | 6566万 | 2423万 | 4143万 | 36.9%    | 1:1.71     | ✓ 正常    |
| bijia  | 813万  | 298万  | 514万  | 36.7%    | 1:1.72     | ✓ 正常    |
| haojia | 441万  | 56万   | 385万  | 12.7%    | **1:6.87** | 🔴 高风险 |
| trend  | 2404万 | 1251万 | 1153万 | 52.0%    | 1:0.92     | 🟡 中风险 |

### 关键发现

1. **Haojia 正负比最极端（1:6.87）**

   - 正样本仅 56 万，负样本 385 万
   - DIN encoder 可能学到 bias（偏向预测负样本）
   - 需要过采样或降低权重

1. **Trend 正负比最均衡（1:0.92）**

   - 是最理想的训练数据分布
   - 但 click 序列完全失效（P50=P90=P99=1）
   - 只能依赖 chajia_50 序列和静态特征

1. **Home 和 Bijia 相对均衡（1:1.7）**

   - 可以作为主要验证对象
   - 序列特征都有效

## 三、建模策略建议

### 推荐配置调整

```protobuf
# 调整辅助任务权重
task_towers {
  tower_name: "bijia_click"
  label_name: "is_bijia_click"
  weight: 1.0  # 保持不变
  task_space_indicator_label: "is_bijia_scene"
}

task_towers {
  tower_name: "haojia_click"
  label_name: "is_haojia_click"
  weight: 0.3  # 降低：正样本太少（56万）
  task_space_indicator_label: "is_haojia_scene"
}

task_towers {
  tower_name: "trend_click"
  label_name: "is_trend_click"
  weight: 0.5  # 降低：序列特征失效
  task_space_indicator_label: "is_trend_scene"
}
```

### 调整后权重分布

| 任务         | 权重    | 占比     |
| ------------ | ------- | -------- |
| CTR          | 4.5     | 56.3%    |
| CVR          | 1.0     | 12.5%    |
| bijia_click  | 1.0     | 12.5%    |
| haojia_click | 0.3     | 3.8%     |
| trend_click  | 0.5     | 6.3%     |
| **总计**     | **7.3** | **100%** |

辅助任务总占比：25.4%（原 35.3%）

## 四、实验验证计划

### Phase 1: 基础验证（1-2天）

```

配置：只加 bijia_click（weight=1.0）
对比：v18 baseline vs v19_bijia_only
评估：Grouped AUC (is_home_scene) 是否提升
```

### Phase 2: 完整实验（3-5天）

```

评估：
  - 主指标：Grouped AUC (is_home_scene)
  - 辅助指标：各场景 AUC 分别评估
```

```
实验组：

  - B: bijia + haojia
  - C: bijia + trend
  - D: bijia + haojia + trend
评估：各组合对 home CTR AUC 的影响
```

## 五、风险评估

### 高风险项

1. **Haojia 过拟合风险**

   - 正样本仅 56 万
   - 缓解：降低权重至 0.3

1. **Trend 序列失效风险**

   - click 序列 P50=1
   - 缓解：降低权重至 0.5

### 中风险项

3. **梯度尺度差异**

   - home 样本量是 haojia 的 14.9 倍
   - 缓解：已降低 haojia/trend 权重

1. **辅助任务权重占比过高**

   - 原 35.3% → 调整后 25.4%
   - 缓解：已调整

### 低风险项

5. **数据泄露（0.39%）**
1. **跨场景样本重叠**
