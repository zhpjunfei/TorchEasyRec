# 对抗式审核：判决实验方案（JUDGE_EXP_DOWNSTREAM_SYNTH_20261104）

> 审核对象：`JUDGE_EXP_DOWNSTREAM_SYNTH_20261104.md`
> 审核方式：红队——按"这实验跑完能不能兑现它承诺的判决"标准逐条攻击。
> 审核日期：2026-11-04。

## 总评

**骨架成立，但有两个立项阻断项。** 配对设计、预注册思想、cross_num=0 陷阱修正、P2 可证伪预测、与 F-B 的命题切割都是对的；
但**判决阈值在统计上自我矛盾**（按自己引用的噪声尺度算，假坐实率 ~34%）、**T0−F1b 是多因子对**（READOUT 原文自标"跨组参考，多因子"，
方案却把它操作化为单因子"target-aware 读出"）——这两点不修订，实验跑完的"坐实/证伪"都立不住。

| #   | 级别     | 发现                                                       | 状态       |
| --- | -------- | ---------------------------------------------------------- | ---------- |
| B1  | **阻断** | 判决阈值与噪声尺度自相矛盾（假坐实率 ~34%、假证伪率 ~16%） | 必须修订   |
| B2  | **阻断** | T0−F1b 多因子对比被当作"target-aware 读出"单因子使用       | 必须修订   |
| P1  | 补丁     | "合成假说整体证伪"过强：PLE 深路合成未被切断               | 改判读框架 |
| P2  | 补丁     | 显著转负（Δ≤−0.1pp）无判决分支                             | 补分支     |
| P3  | 补丁     | 容量混杂（K1 摘 252 条 → 维度/参数量变）未进解读纪律       | 补限定     |
| W1  | 措辞     | 阈值出处、多 seed 补跑范围、run 作废规则缺失               | 补字句     |

## B1【阻断】判决阈值在统计上不成立

方案 §一自己写的依据："单 seed 噪声尺度 ~0.07pp≈0.3σ" → **σ_Δ ≈ 0.25pp**（配对差的跨 seed 标准差）。
但判据给的是：坐实 ≥ +0.10pp、证伪带 |Δ| ≤ 0.05pp。按 σ=0.25pp 算【推断，正态近似】：

| 场景                             | 现规则的行为                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------- |
| 真实效应 = 0                     | 假坐实 P(Δ≥0.10)=P(Z≥0.4)≈**34%**；能走到"证伪" P(\|Δ\|≤0.05)≈**16%**；其余 ~50% 未决 |
| 真实效应 = +0.3pp                | 仍有 P(Δ≤0.05)≈**16% 被误证伪**；坐实概率仅 ~79%                                      |
| 差中差（Δ_C 与 −0.011pp 起点比） | 两对 run 独立训练，噪声再乘 √2，更差                                                  |

即：这套阈值**跑出来的判决掷硬币成分过大**——尤其"假坐实 1/3"这个量级，对一个要回写 SQL 链【推断】标注的判决不可接受。
方案里"未决 → 触发 ≥3 seed"是补救阀，但阈值本身会让 1/3 的假阳性直接拿到"坐实"票、根本走不到补救阀。

**修订（判据 v2，推荐）**：3 seed/细胞（T0/F1b 跨臂用**同一组 seed**，配对消噪），判决看均值 + 符号一致性：

| 读数（3 seed）                           | 判决                                           |
| ---------------------------------------- | ---------------------------------------------- |
| 3/3 Δᵢ>0 且 mean Δ ≥ +0.15pp             | 坐实（≈1σ_mean 且过符号闸，假坐实 \<10%）      |
| 3/3 \|Δᵢ\| ≤ 0.15pp 且 \|mean\| ≤ 0.05pp | 证伪（等效性带，不是"没看见"）                 |
| 其余                                     | 未决（含符号不一致）→ 扩到 5 seed 或如实报未决 |

**功效的诚实预期**【推断】：3 seed 的 σ_mean≈0.14pp，本设计的**最小可检测效应 ≈0.2~0.3pp**。
若真实合成效应就在 0.1pp 量级（T2−T0 同量级），任何务实预算内都只能出"未决"——
**本实验只能判决"合成吸收量级是否 ≥0.2pp"的大效应问题**，这点必须先写进预期，否则事后会把"未决"误读成"没效应"。

**备选（成本敏感版）**：P0 先单 seed 宽阈值筛（坐实 ≥+0.5pp≈2σ；任何落在 ±0.5pp 内一律进 seed 流程）——按功效算单 seed 宽阈值会把大量真效应推给二阶段，省算力有限，不如直接 3 seed。两版成本：严谨版 2 干预×2 臂×3 seed=12 run；只跑 P0 则 6 run。

## B2【阻断】T0−F1b 是多因子对比，不能代表"target-aware 读出"

READOUT_20261030_T0_T3.md 原文自己标了：**"T0 − F1b（跨组参考，多因子）：transformer 块+门控+点积读出 vs 裸 self-attn"**。
T0 与 F1b 之间至少有三个差异：①编码器块（TransformerEncoder 块 vs self_attention_encoder）②读出（target 门控点积 vs 池化）③门控结构。
方案 §一却把判决操作化为"target-aware 读出 vs 无 target 读出"——**若 Δ_C 拉开，可能是块结构或门控在无 DCN 环境下变珍贵，归因不唯一**。

**修订（二选一）**：

- **A（零成本，必须做）**：把命题措辞降级——判决对象改称"T0 形态整体（transformer 块+门控+target 读出）vs F1b 形态（裸 self-attn）"，
  结论禁止写成"target-awareness 单因子"；SQL 链 §5.7 回写时同步降级措辞。
- **B（+1 run/骨干，可选）**：加单变量探针 T0-mp（T0 同块同门控、读出换均值池化）——(T0 vs T0-mp) 才是干净的"target 读出开/关"对，
  T0-mp vs F1b 则度量块结构贡献。若预算允许，P0 用 T0-mp 替换 F1b 成为判决对更干净。

## P1【补丁】"合成假说整体证伪"过强——PLE 深路没关

C1 只删 DCNv2 乘性交叉；**PLE 的 MLP 深路仍接收 (target emb, seq 池化, kv) 拼接并做非线性合成**。
Δ_C≈0 的合法结论只有"**DCN 交叉不是吸收器**"；"下游合成"的弱版本（PLE 深路合成）完全存活。
§二"都不拉开 → 合成假说整体证伪"、§一"假说证伪"都超出了干预的覆盖范围。

**修订**：判决表加一行——Δ_C≈0 且 Δ_K≈0 ⇒ "强版（DCN 交叉合成）证伪；弱合成（PLE 深路）存活"，
后续补救臂 = C2（把 seq 池化输出从 all 组隔离或先降维再进主干）或 K2（domain 组 kv 也摘，方案已备）。
"证伪"的替代方向（序列输出通路容量）保留，但列为并存候选而非唯一。

## P2【补丁】显著转负没有分支

现判据三行覆盖不了 Δ ≤ −0.10pp：按字面会掉进"未决"。但转负是**信息量最大的结果之一**——
它意味着 DCN 不是 F1b 的追赶器、反而是 **T0 显式信号的放大器**（拆掉后 T0 反而更吃亏）。
此时"T2−T0 会变大"的 P2 预测也应**反转**（放大器模型下残差视图同样依赖下游放大，T2−T0 可能缩）。

**修订**：加分支——Δ ≤ −0.10pp（过符号闸）⇒ "吸收器假说证伪、**放大器假说立起**"，P2 预测方向反转登记，后续判读框架整体切换。

## P3【补丁】容量混杂要进解读纪律

K1 摘 252 条 kv：`all` 组 1096→~844，`_main_group_dim` 缩、DCN/EPNet/PPNet 参数量变；C1 删 cross 后 concat 宽度变。
方案只声明"绝对 AUC 必降不看"，但**容量变化对两臂差异性影响**（如 F1b 池化向量更冗余、抗容量损失更强）可以伪造或掩盖 Δ。
placebo 臂（摘等量非 kv 特征）成本高，不必跑，但**解读纪律**要写：Δ_K 若拉开，先排除"容量差异性打击"解释
（看 train AUC 是否同幅掉、PRED_STATS 分布形态），才允许归因 kv 原料。

## W1【措辞】三处小补

1. "~0.07pp≈0.3σ" 出处标一下（多 seed 讨论轮的推断，非实测多 seed 数据）；
1. "未决 → ≥3 seed"写明补跑范围：涉事对比的**全部 4 个细胞**（含 base 对，若用差中差判）；
1. 加 run 作废规则：NaN/退化指纹（0.49962…）/指纹对不上 → 该 run 作废重跑，不进判决。

## 保留好评（不改）

## 结论

**不建议按现版立项；按 B1（判据 v2）+ B2（措辞降级或 T0-mp）+ P1/P2（判读框架）修订后可立项。**
修订后实验的诚实定位：**判决"下游合成吸收量级是否 ≥0.2pp"**——大效应可判、0.1pp 量级效应留给多 seed 长跑，不许在"未决"上硬解释。
