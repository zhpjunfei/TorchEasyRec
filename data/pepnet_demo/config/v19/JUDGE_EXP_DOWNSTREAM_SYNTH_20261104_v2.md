## 一、判决逻辑 v2（吸收 B1/P1/P2）

**命题（B2 修订后的措辞，降级版）**：本实验判决的是
**"T0 形态整体（transformer 块+门控+target 点积读出）相对 F1b 形态（din+self-attn 池化）的差距，
是否被下游合成吸收"**——不是"target-awareness 单因子"（T0−F1b 是多因子对：块结构+门控+读出三者皆异，
READOUT 原文自标"跨组参考，多因子"）。若需单因子归因，另加 T0-mp 探针臂（同块同门控、读出换均值池化——
需新增 `readout_type:"mean_pool"` 代码 + fx trace 测试，本批不动）。

**判据 v2（3 seed 配对 + 符号闸，替换 v1 的单 seed 三段表）**——σ_Δ≈0.25pp（0.074≈0.3σ 的推断），
v1 阈值（坐实 0.10pp）假坐实率 ~34%，废弃；改用：

| 读数（每细胞 3 seed，T0/F1b 跨臂用同一组 seed） | 判决                                                                       |
| ----------------------------------------------- | -------------------------------------------------------------------------- |
| **3/3 Δᵢ > 0 且 mean Δ ≥ +0.15pp**              | **坐实**（吸收器版成立）                                                   |
| **3/3 Δᵢ < 0 且 mean Δ ≤ −0.15pp**              | **放大器版立起**（DCN 是 T0 信号的放大器而非 F1b 追赶器；P2 预测反转登记） |
| **3/3 \|Δᵢ\| ≤ 0.15pp 且 \|mean\| ≤ 0.05pp**    | **证伪强版**（DCN 交叉合成不是原因；注意 P1 限定）                         |
| 其余（含符号不一致）                            | **未决** → 扩 5 seed 或如实报未决，禁止硬解释                              |

- 判决对象 = Δ = (T0−F1b) 的 ctr 差；cvr、train@5500 同向为佐证，方向不一致进"未决"。
- 起点 base（−0.011pp）视为 0 处理（|−0.011| ≪ σ），**判决看 Δ 本身 vs 0**，不做差中差（避免 √2 噪声放大）；base 不重跑。
- **功效预注册**：3 seed 的 σ_mean≈0.14pp，最小可检测效应 ≈0.2~0.3pp。本实验只判决
  **"合成吸收量级是否 ≥0.2pp"** 的大效应问题；0.1pp 量级真效应在务实预算内只能"未决"——不得把"未决"读成"没效应"。

**判读框架 v2（吸收 P1/P2）**：

| Δ_C              | Δ_K      | 判决                                                                                                                            |
| ---------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 坐实             | 任意     | DCN 交叉是吸收器；Δ_K 决定原料是否含 target-keyed kv                                                                            |
| 坐实             | 坐实     | 合成路径 = kv×target 经 DCN 交叉，完整坐实                                                                                      |
| 证伪强版         | 证伪强版 | **只证伪"DCN 交叉合成"强版**——PLE 深路弱合成仍存活（C2/K2 才能关死）；替代候选=序列输出通路容量、读出本身无信息（并列，不唯一） |
| 放大器版（转负） | 任意     | 吸收器假说证伪、放大器假说立起；后续 T2−T0 预测**反转**（应缩不涨）                                                             |
| 未决             | 未决     | 报未决，扩 seed；禁止叙事                                                                                                       |
