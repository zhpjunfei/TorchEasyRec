## 四、副发现

1. **P0-2a 是唯一双指标同正臂**（cvr +0.044 同向），且 20261030 窗的 T0~T3 系列没有任何单变量达到 +0.24pp——ts 补全（近因信息进 chajia/search）是 12 跑以来最大单变量正读数【事实读数】。
1. **P0-2b 归因警示**【事实读数】：该臂是三因子捆绑（time_gate×4 + 输出维度变化 + grad_clipping 搭车），本就声明归因松。跌出预期下限（−0.198 vs −0.05）提示某因子有额外伤害，但**不追查**——弃置成本最低；若将来重访，须拆臂（单 time_gate、无搭车）。
1. P0-4 的 Δcvr≈0.009 近零——exposure rt 的收益面在 ctr 侧，与 20261030 窗曝光族（+0.52pp ctr / −0.09pp cvr 形态）同构【推断】。
1. GRAD_CONFLICT 无红灯（ema cos 0.046~0.102）；PRED_STATS probs_ctr 均值 0.366~0.370 贴 label 均值 0.367，无校准漂移。

## 六、seed2/3 执行单（20261111 补）

**机制核查**【事实读数】：种子由环境变量控制，**不改代码**——`tzrec/__init__.py` L65-72：

- `TORCH_MANUAL_SEED`（默认 **"42"**）→ torch.manual_seed + random.seed（权重初始化 + torch 侧随机）
- `NUMPY_MANUAL_SEED`（默认 **"42"**）→ np.random.seed
- `USE_DETERMINISTIC_ALGORITHMS`（默认 "1"）→ 确定性算法已开
- `dataset.py` L816-828：dataloader worker 种子 = `EVAL_SEED`（若 >0）否则 `TORCH_MANUAL_SEED`，+worker_id
- `main.py` L176-179：`EVAL_SEED`>0 时 eval 前重播种（eval 确定性）

历史全部实验 = 默认 42。**seed2/3 = 启动命令前缀 env 换值**，例如挂到现有训练命令前：

```bash
# seed2
TORCH_MANUAL_SEED=43 NUMPY_MANUAL_SEED=43 EVAL_SEED=43 <原训练命令>
# seed3
TORCH_MANUAL_SEED=44 NUMPY_MANUAL_SEED=44 EVAL_SEED=44 <原训练命令>
```

**配对纪律（方案 A 跑序）**：

| 序  | config         | env seed | 记录名建议                     |
| --- | -------------- | -------- | ------------------------------ |
| 1   | v6f_kv_fusion  | 43       | 20261109_v6f_kv_fusion_seed43  |
| 2   | v6f_p02a_seqts | 43       | 20261109_v6f_p02a_seqts_seed43 |
| 3   | v6f_kv_fusion  | 44       | 20261109_v6f_kv_fusion_seed44  |
| 4   | v6f_p02a_seqts | 44       | 20261109_v6f_p02a_seqts_seed44 |

- 同 seed 的 base 与臂**必须同 env**（配对的定义）；Δ 配对账 = {Δ_42=+0.240, Δ_43, Δ_44}，闸判读不变（3/3 同号 + |mean| ≥ 0.15pp）。
- 三个变量取同一数值（43/43/43）；`EVAL_SEED` 一并设，保证 worker 与 eval 播种在配对两侧一致。20261109 样本集、eval 口径、T_max 纪律照旧。
- ⚠ 诚实边界：该 fork 的 sampler cluster（`launch_sampler_cluster`）是否吃 torch 种子**未核验**——env 保证的是"配对两侧除 config 外环境全同"；若采样顺序本身不确定，Δ 方差偏大，符号闸正是兑这个的。
- ⚠ 若训练平台吞环境变量（容器/调度器不透传），才考虑改 `tzrec/__init__.py` L65/68 默认值——**改代码需先经你同意**；优先在启动命令/作业描述里前缀 env 并在日志头记录实际生效值。
