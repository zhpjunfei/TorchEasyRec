## 一、Decay 机制原理

### 1.1 参数含义

| 参数       | 当前值 | 含义                               |
| ---------- | ------ | ---------------------------------- |
| decay_rate | 0.9    | 每 decay_step 步，样本权重乘以 0.9 |
| decay_step | 100    | 权重衰减的步长间隔                 |
| 半衰期     | ~658步 | 样本权重降至初始 50% 所需的步数    |

### 1.2 数学表达

```
weight(t) = decay_rate ^ (t / decay_step)
          = 0.9 ^ (t / 100)

半衰期 T_0.5:
0.5 = 0.9 ^ (T_0.5 / 100)
T_0.5 = 100 * ln(0.5) / ln(0.9) ≈ 658 步
```

### 1.3 Weight 衰减曲线

```
步数    权重      说明
─────────────────────────────
0       1.0000    最新样本
100     0.9000    衰减10%
200     0.8100    衰减19%
400     0.6561    衰减34%
658     0.5000    ← 半衰期点
1000    0.3487    衰减65%
2000    0.1216    衰减88%
4000    0.0148    衰减98%
```

│  - 一半样本权重已衰减                                        │

│  - 如果还波动 → 需要调整参数                                 │
├─────────────────────────────────────────────────────────────┤
│  阶段4: 稳定期 (>1316步)                                      │
│  - 样本权重分布均匀                                          │

### 方案4: 自适应 Decay

根据 GAUC 波动自动调整参数：

```python
def adaptive_decay(gauc_history, current_decay_rate, current_decay_step):
    window = gauc_history[-500:]
    std = np.std(window)
    trend = abs(window[-1] - window[0])

    if std > 0.01:
        # 波动大，减慢衰减（增大半衰期）
        new_decay_step = min(current_decay_step * 1.1, 500)
    elif std < 0.003 and trend < 0.001:
        # 稳定，可以加快衰减
        new_decay_step = max(current_decay_step * 0.9, 50)
    else:
        new_decay_step = current_decay_step

    return current_decay_rate, new_decay_step
```

## 五、总结

### 核心结论

1. **当前可能还在波动期**

   - 半衰期 658 步，需要 > 1316 步才能稳定
   - 建议继续训练或调整 decay 参数

1. **推荐优化方向**

   - 增大 decay_step（200-500）以加快收敛
   - 或使用自适应 decay 自动调整
   - 增加评估窗口到 1500 步

1. **判断收敛的标准**

   - GAUC 滑动标准差 < 0.005
   - GAUC 滑动均值变化 < 0.001
   - 训练步数 > 3 × 半衰期
