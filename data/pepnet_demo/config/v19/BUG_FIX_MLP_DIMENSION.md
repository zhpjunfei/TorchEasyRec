# Bug修复：MLP维度不匹配

**日期**: 2026-10-21
**错误类型**: RuntimeError - tensor维度不匹配
**修复状态**: ✅ 已修复（2026-10-22 修正落点，见下）

> **修订（2026-10-22，对抗性审核后）**：本文档初版把修复记在 `multiscene_v2_fix_label_leak.config` 上，**与盘面不符**——v2 配置 5 塔本来就是 `[512,256,128]`（从未有 `[128,64]`，不存在此崩溃）。真正携带 `[128,64]` 的是 **4 个 phase 配置**（phase1_chajia / p0 / p0_v2 / search 的 3 个辅助塔）。修复已于 2026-10-22 落到这 4 个文件上，且**统一为 `[512, 256, 128]`**（而非初版写的 `[128,64,128]`）——与 multiscene 基线及 phase1_bijia_only / phase2_bijia_haojia 的辅助塔宽度对齐，顺带消除"跨 Phase 辅助塔宽度不一致"的混淆变量。

______________________________________________________________________

## 一、错误信息

```
RuntimeError: The size of tensor a (128) must match the size of tensor b (64) at non-singleton dimension 0
```

**位置**: `pepnet_dcn_ple.py:1010` - `compute_gradient_conflict()`

______________________________________________________________________

## 二、问题原因

### 2.1 Tower MLP配置不一致

| Tower        | 原MLP配置             | 输出维度 |
| ------------ | --------------------- | -------- |
| ctr          | \[512, 256, **128**\] | 128      |
| cvr          | \[512, 256, **128**\] | 128      |
| bijia_click  | \[128, **64**\]       | 64 ❌    |
| haojia_click | \[128, **64**\]       | 64 ❌    |
| trend_click  | \[128, **64**\]       | 64 ❌    |

### 2.2 梯度冲突计算逻辑

```python
# pepnet_dcn_ple.py:1000-1010
for i in range(len(names)):
    for j in range(i + 1, len(names)):
        g1 = grads[names[i]]  # 128维
        g2 = grads[names[j]]  # 64维
        cos_sim = F.cosine_similarity(g1, g2, dim=0).item()  # ❌ 维度不匹配
```

**问题**：余弦相似度要求两个tensor维度相同。

______________________________________________________________________

## 三、修复方案

### 3.1 修改内容（2026-10-22 实际落盘）

统一辅助任务MLP输出维度为128，并与基线宽度对齐：

```diff
- hidden_units: [128, 64]
+ hidden_units: [512, 256, 128]
```

（初版方案 `[128,64,128]` 虽能修崩，但会留下"辅助塔宽度与基线/同族 phase 不一致"的混淆变量；统一为 `[512,256,128]` 一并解决。）

### 3.2 修改后的配置（全部 9 个配置末维均为 128）

| Tower                                                                    | 修改后MLP配置   | 输出维度 |
| ------------------------------------------------------------------------ | --------------- | -------- |
| ctr / cvr                                                                | [512, 256, 128] | 128 ✅   |
| bijia_click / haojia_click / trend_click（4 个 phase 配置，原 [128,64]） | [512, 256, 128] | 128 ✅   |

### 3.3 文件位置（实际修复的 4 个文件）

```
config/v19/home_flow_2608_v19_phase1_chajia.config
config/v19/home_flow_2608_v19_phase1_p0.config
config/v19/home_flow_2608_v19_phase1_p0_v2.config
config/v19/home_flow_2608_v19_phase1_search.config
```

验证：9 个 `.config` 全部解析通过、各塔末维集合 = {128}、`[128, 64]` 残留 = 0。
