## 四、核心发现

### 4.1 out_task_space_weight 机制

```protobuf
task_space_indicator_label: "is_click"
in_task_space_weight: 1
out_task_space_weight: 0.01
```

- **in_task_space**（点击 5% 样本）：CVR 全量 BCE
- **out_task_space**（非点击 95% 样本）：CVR 以 0.01 权重 BCE

梯度贡献占比：`95% × 0.01 / (5% × 1 + 95% × 0.01) ≈ 19%`。这 19% 的弱负信号比 CTR weight 放大更直接有效。

### 4.2 核心发现：ots × dropout 协同（2026-06-26 更新）

**← 旧结论（两轮推翻）：** "ots 与 dropout 互斥" → "ots 与 dropout 协同" → **"dropout 越高越好（在 ots 配合下）"**

**关键新数据（fix 后）：**

| 实验               | out_task | CVR dropout |    Δcvr    | 解释                          |
| :----------------- | :------: | :---------: | :--------: | :---------------------------- |
| **ots002** 🚀      |   0.02   |     0.1     |   +0.57%   | 最优 ots 值                   |
| **ots005** 🚀      |   0.05   |     0.1     |   +0.50%   | ots 略过饱和                  |
| **dropout03** 🚀   |   0.01   |   **0.3**   |   +0.41%   | 更高 dropout = 更好 CVR       |
| Config C           |   0.01   |     0.1     |   +0.18%   | 基线                          |
| ots0005            |  0.005   |     0.1     |   +0.02%   | ots 过低                      |
| Config B           |    0     |     0.3     |   −0.10%   | 纯 dropout 无 ots → 有害      |
| **dropout0** ❌    |   0.01   |    **0**    | **−0.83%** | 无 dropout → 过拟合，CVR 崩塌 |
| **dropout0_ls005** |   0.01   |      0      | **−0.74%** | LS 弱补偿无效                 |

**ots 最优值（dropout=0.1 固定）：** 0.005 → 0.01 → **0.02** → 0.05，峰值在 0.02（+0.57%），0.05 略降（+0.50%）。

**dropout 与 CVR 的正相关（ots=0.01 固定）：** d=0 → **−0.83%**，d=0.1 → +0.18%，d=0.3 → **+0.41%**。无 dropout 时，CVR tower 在少量转化样本上严重过拟合，ots 的非点击梯度无法补偿容量损失。dropout 越高，正则化越强，泛化越好。

**修复后的重要认知：** 修复前 dropout 未生效，等效于 d=0 → +0.43%，修复后 d=0 → −0.83%。旧结论被推翻——**ots 必须配合 dropout 才有正向效果，且 dropout 越高越好**.

### 4.3 已证否的方向

| 方向              | 证据                     | 结论                     |
| :---------------- | :----------------------- | :----------------------- |
| 梯度隔离          | isolate −1.15%           | ❌ CVR 梯度有价值        |
| 自适应加权        | uw −0.09%, pareto −0.26% | ❌ 不如手动调权          |
| 梯度手术          | pcgrad 全部负向/中性     | ❌ 无益                  |

| label_smoothing   | dropout0_ls005 −0.74%    | ❌ 无法补偿 dropout 缺失 |
