# isNewItem_fg — 模型对新帖不存在排序能力问题

## 背景

- 线上 re-rank 新帖曝光占比低，30% 差距
- 怀疑模型对新帖排序能力差
- 引入 `isNewItem_fg` 特征 + `segment_auc` / `grouped_auc` + predict 打分校验

## 实验设计

| 步骤        | 内容                                                                             |
| ----------- | -------------------------------------------------------------------------------- |
| 1. 特征接入 | SQL 产出 `isnewitem_fg ARRAY<STRING>['0'/'1']`，`stub_type: true` 不改变模型架构 |
| 2. 训练指标 | `segment_auc{target:0/1}` + `grouped_auc{isnewitem_fg}`                          |
| 3. 预测校验 | `predict_checkpoint` 输出全量分数，SQL 统计分布                                  |

## 一、segment_auc — 排序能力验证

> Eval Epoch-0 日志：

| 行      | 任务    | segment       | AUC        | mean_target            | 样本量    |
| ------- | ------- | ------------- | ---------- | ---------------------- | --------- |
| 第 1 行 | **CTR** | 旧帖 target:0 | 0.7138     | **0.372**（点击/曝光） | 2,708,913 |
|         |         | 新帖 target:1 | **0.7257** | **0.385**（点击/曝光） | 1,273,240 |
| 第 2 行 | **CVR** | 旧帖 target:0 | 0.7590     | **0.125**（转化/曝光） | 2,708,913 |
|         |         | 新帖 target:1 | **0.7619** | **0.134**（转化/曝光） | 1,273,240 |

|     | 全局 auc | grouped_auc（组加权） | 说明                                      |
| --- | -------- | --------------------- | ----------------------------------------- |
| CTR | 0.7178   | **0.7198**            | 新帖组 AUC 更高，分组后不被大样本旧帖稀释 |
| CVR | 0.7600   | **0.7605**            | 差距微小                                  |

> **结论：新帖 AUC(CTR 0.726, CVR 0.762) ≥ 旧帖(0.714, 0.759)，模型排序能力不存在问题。**

## 二、predict_checkpoint — 预测分分布验证

> 数据集 `val 20260707`，4M 条

### CTR 预测分

| 统计量 | 老帖  | 新帖      | 差异           |
| ------ | ----- | --------- | -------------- |
| avg    | 0.376 | **0.389** | +3.5%          |
| std    | 0.179 | **0.191** | 新帖离散度更大 |
| p25    | 0.256 | 0.256     | 持平           |
| median | 0.331 | **0.339** | +2.4%          |
| p75    | 0.456 | **0.485** | +6.4%          |

```
          p25  median    p75
老帖    0.256  0.331   0.456   ← avg=0.376
新帖    0.256  0.339   0.485   ← avg=0.389
              ↑+0.008  ↑+0.029  分布右移
```

### CVR 预测分

| 统计量 | 老帖  | 新帖      | 差异  |
| ------ | ----- | --------- | ----- |
| avg    | 0.329 | **0.334** | +1.5% |
| std    | 0.220 | 0.220     | 持平  |

> CVR 分位数因 SQL 复用 CTR `row_num` 不可信，略过。

### 实际 转化/点击 vs 模型预测

|                                    | 老帖           | 新帖           |
| ---------------------------------- | -------------- | -------------- |
| **A** CTR mean_target（点击/曝光） | 0.372          | 0.385          |
| **B** CVR mean_target（转化/曝光） | 0.125          | 0.134          |
| **实际 转化/点击 = B ÷ A**         | **0.336**      | **0.348**      |
| probs_cvr 预测 avg                 | **0.329**      | **0.334**      |
| 偏差                               | -0.007 (-2.1%) | -0.014 (-4.0%) |

> CVR mean_target(0.125) 是 `转化/曝光`，probs_cvr 预估 `转化/点击`，分母不同不直接可比。用 `CVR÷CTR` 换算后对比，模型校准性很好，偏差 2~4%。

### 全部指标汇总

| 维度           | 指标              | 旧帖      | 新帖       |
| -------------- | ----------------- | --------- | ---------- |
| **排序能力**   | AUC CTR           | 0.7138    | **0.7257** |
|                | AUC CVR           | 0.7590    | **0.7619** |
| **预测分**     | CTR avg           | 0.376     | **0.389**  |
|                | CVR avg           | 0.329     | **0.334**  |
| **实际 label** | 点击/曝光         | 0.372     | **0.385**  |
|                | 转化/曝光         | 0.125     | **0.134**  |
|                | 转化/点击（推算） | 0.336     | **0.348**  |
| **样本量**     | —                 | 2,708,913 | 1,273,240  |

> **所有维度指向一致：新帖 ≥ 旧帖，模型不存在打压新帖。**

## 最终结论

> **模型对新帖的排序能力不存在问题。**

30% re-rank 差距应排查：

| 方向       | 原因                                         |
| ---------- | -------------------------------------------- |
| 粗排截断   | 新帖在粗排阶段已被过滤，精排看不到           |
| 偏置因素   | 曝光偏置、位置偏置，新帖缺少历史曝光积累     |
| 新鲜度信号 | `pub_hours` 等未作为特征进入精排，模型无感知 |
